# Archived source files

This directory keeps byte-exact source files separate from their readable Hugo archive views. The old website source files come from commit [`43fb08a65bdf4341d78adb829ffcd6cc5e4d8131`](https://github.com/praxis-proxy/praxis-proxy.github.io/tree/43fb08a65bdf4341d78adb829ffcd6cc5e4d8131). Example YAML copies come from the pinned Praxis v0.7.2 and Praxis AI v0.7.0 snapshots and are labelled as such; they cannot establish the exact bytes that the old page fetched from mutable `main`.
